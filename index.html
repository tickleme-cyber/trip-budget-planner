OOP Architecture & Viva Guide

This project was architected strictly around core Object-Oriented Programming (OOP) principles. Use this cheat sheet to confidently answer questions during your college practical/viva exam.

1. Encapsulation

Implemented

Data hiding and bundling of state and behavior. All model classes (Trip, Expense, Traveler) use strict private fields (#id, #totalBudget, #baseAmount) accessible only via validated getters and setters.

// js/models/Traveler.js class Traveler { #id; #name; #email; get name() { return this.#name; } setName(val) { if(!val) throw new Error("Name required"); this.#name = val; } }

2. Inheritance

Implemented

Code reuse through hierarchical classification. Expense is the base class. Subclasses extend it: FlightExpense, HotelExpense, FoodExpense, TransportExpense, ActivitiesExpense, ShoppingExpense.

// js/models/ExpenseSubclasses.js export class FlightExpense extends Expense { #baggageFee; #airportTax; constructor(params) { super({ ...params, category: 'Flight' }); this.#baggageFee = params.baggageFee; } }

3. Polymorphism & Method Overriding

Implemented

The base class Expense defines calculateTotalCost(). Each subclass overrides this method with category-specific pricing. The Trip iterates polymorphically.

// Polymorphic method call in Trip.js getTotalSpent() { return this.#expenses.reduce((sum, exp) => sum + exp.calculateTotalCost(), 0); }

4. Composition ("HAS-A" Relationship)

Implemented

A Trip has-a collection of Traveler objects (#travelers = []) and has-a collection of Expense objects (#expenses = []).

// js/models/Trip.js class Trip { #travelers; // Composition: contains Traveler[] #expenses; // Composition: contains Expense[] }

5. Strategy Pattern & Polymorphic Estimation

Implemented

The Budget Recommendation Engine implements the Strategy Pattern. TravelStrategy is the abstract base, extended by BackpackerStrategy, ModerateStrategy, and LuxuryStrategy. Polymorphic cost estimation calculates tailored accommodation, food, and transport multipliers for any budget.

// js/models/TravelStrategy.js class BackpackerStrategy extends TravelStrategy { getStayMultiplier() { return 0.48; } // Hostels } class LuxuryStrategy extends TravelStrategy { getStayMultiplier() { return 2.25; } // 5★ Resorts }

6. Important Classes in this Project

Trip Encapsulates destination, dates, budget, composition of travelers & expenses
Expense Base class with encapsulated attributes and calculateTotalCost()
Flight / Hotel / Food / Transport Expense Derived subclasses with specialized pricing rules and overridden methods
Traveler Encapsulates traveler identity, initials, and visual color token
Destination Encapsulates destination benchmarks, vibes, ratings, and cost calculation
RecommendationEngine Service evaluating budget fit, match scores, and 1-click Trip generation
ExpenseSplitter Service class calculating fair shares, net balances, and greedy debt simplification

What Am I Looking At?

COSMIC TELEMETRY · OOP SYSTEM ARCHITECTURE

✦ 01 // OBJECT-ORIENTED PROGRAMMING FOUNDATION

TripBudget is an enterprise-grade Object-Oriented application applying the four pillars of OOP:

  • Encapsulation: Private fields (#id, #name, #email) guarded by validated getters/setters.
  • Inheritance: Expense is the abstract base class inherited by FlightExpense, HotelExpense, FoodExpense, TransportExpense, ActivitiesExpense, and ShoppingExpense.
  • Polymorphism: Dynamic runtime cost evaluation via calculateTotalCost() specialized per subclass (taxes, baggage, tips, nights, discounts).
  • Composition: A Trip has-a list of Traveler instances and has-a list of Expense instances.

✦ 02 // GREEDY DEBT SIMPLIFICATION ALGORITHM

The ExpenseSplitter service calculates net balances for all group members and executes a greedy settlement algorithm: Minimizes overall transactions to settle all trip debts across travelers efficiently in O(N log N) time.

✦ 03 // STAR PARTY COSMIC VISUAL INTERFACE

Inspired by the award-winning Star Party celestial aesthetic: real-time astronomical HUD telemetry, interactive HTML5 constellation map, high-contrast monospace technical telemetry, and print-ready PDF export.
