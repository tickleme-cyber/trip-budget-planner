# ✈️ Trip Budget Planner - Object-Oriented Programming (OOP) College Project

A simple, modern, and fully functional **Trip Budget Planner** web application designed to demonstrate core **Object-Oriented Programming (OOP)** principles in practice.

---

## 🎯 Project Overview

Planning a trip with friends involves estimating costs, tracking expenses, staying within budget, and fairly settling "who owes whom". This application provides a comprehensive solution while maintaining a clean, clean-coded OOP architecture.

### ✨ Key Features
1. **Trip Creation & Management**:
   - Trip Name, Destination, Dates, Total Budget, and multiple Travelers.
   - Switch between multiple trips seamlessly.
2. **Expense Management**:
   - Add, edit, and delete expenses with descriptions, base amount, date, category, and payer.
   - Supported categories: **Flight, Hotel, Food, Transport, Activities, Shopping, Other**.
3. **Budget Dashboard**:
   - Real-time tracking of **Total Budget**, **Total Spent**, **Remaining Budget**, and **Budget Usage Percentage**.
   - Dynamic animated progress bar.
   - Automatic visual warning when nearing budget limit (≥ 80%) or exceeding budget (> 100%).
4. **Expense Splitting & Settlement**:
   - Fairly split any individual expense or overall trip expenses among selected participants.
   - Computes per-traveler net balances (who paid vs. who owes).
   - Solves the **"Who Owes Whom"** challenge using an optimal **Greedy Debt Simplification Algorithm** (Min-Cash-Flow) to minimize total transactions.
5. **Category Spending Breakdown**:
   - Interactive SVG Donut Chart and responsive visual category progress bars.
6. **"Where Can I Go?" Budget Travel Recommendation System**:
   - Intelligent destination discovery based on given budget, duration, party size, and vibe.
   - Dynamic itemized cost estimations for **Flights, Accommodation, Food, and Activities**.
   - **Strategy Pattern** with polymorphic travel styles: **Backpacker (Budget)**, **Moderate (Comfort)**, and **Luxury (VIP)**.
   - Multi-currency support (**USD, INR, EUR, GBP, AED, JPY, etc.**) with live budget sliders and presets.
   - **1-Click Trip Generator**: Seamlessly creates a new `Trip` with encapsulated `Traveler` instances and initial polymorphic `Expense` objects generated by `ExpenseFactory`.
7. **Input Validation**:
   - Non-negative amounts, required fields, date order verification, and informative toast notifications.

## 🔬 Polymorphic Formulas Explained

Each expense subclass implements unique financial business logic:

1. **`FlightExpense`**:
   $$\text{Total Cost} = \text{baseAmount} + \text{baggageFee} + \text{airportTax}$$
2. **`HotelExpense`**:
   $$\text{Total Cost} = (\text{baseAmount} \times \text{nights}) \times (1 + \frac{\text{serviceTaxPercent}}{100})$$
3. **`FoodExpense`**:
   $$\text{Total Cost} = \text{baseAmount} + \text{tipAmount} + \text{taxAmount}$$
4. **`TransportExpense`**:
   $$\text{Total Cost} = \text{baseAmount} + \text{tollCharges} + \text{parkingFee}$$
5. **`ActivitiesExpense`**:
   $$\text{Total Cost} = \text{baseAmount} + \text{equipmentRentalFee}$$
6. **`ShoppingExpense`**:
   $$\text{Total Cost} = \max(0, \text{baseAmount} + \text{salesTax} - \text{discount})$$

When `trip.getTotalSpent()` executes, JavaScript invokes each item's overridden `calculateTotalCost()` method via runtime polymorphic dispatch.

## 🤝 Debt Settlement Algorithm (ExpenseSplitter)

The `ExpenseSplitter` class computes individual balances:
$$\text{Net Balance} = \text{Total Paid by Traveler} - \text{Total Fair Share}$$

- **Creditor (Net > 0)**: Entitled to receive money.
- **Debtor (Net < 0)**: Must pay money.

### Greedy Min-Cash-Flow Algorithm:
1. Sort creditors descending by amount owed to them.
2. Sort debtors descending by amount they owe.
3. Match the largest debtor with the largest creditor:
   $$\text{Payment} = \min(|\text{Debtor Balance}|, \text{Creditor Balance})$$
4. Record transaction: `Debtor pays Creditor $Payment`.
5. Reduce balances and repeat until all debts are settled to within $0.01.

## 🎓 College Viva Questions & Answers

### Q1: What is Encapsulation and where is it in this project?
> **Answer**: Encapsulation is the mechanism of bundling data and the methods that operate on that data into a single unit (class), while restricting direct access to internal state. In this project, private fields using the `#` symbol (e.g. `#id`, `#totalBudget`, `#baseAmount`) prevent unauthorized outside modification. Modifying or reading them requires public getters and validated setter methods.

### Q2: Why did you use Inheritance for Expenses?
> **Answer**: All expenses share common attributes like title, date, payer, participants, and base amount. Instead of duplicating these fields across separate classes, we created a single base class `Expense`. Subclasses like `FlightExpense` and `HotelExpense` inherit these common features via `extends Expense` and add only their domain-specific properties (such as baggage fees or number of nights).

### Q3: How is Polymorphism demonstrated?
> **Answer**: The base class `Expense` defines `calculateTotalCost()`. Each subclass overrides `calculateTotalCost()` with its own specific pricing algorithm. In `Trip.getTotalSpent()`, we iterate through a heterogeneous array of expenses and call `exp.calculateTotalCost()` without needing `if/else` checks for each class type. The runtime dynamically invokes the correct subclass method.

### Q4: What is the difference between Composition and Inheritance in this app?
> **Answer**:
> - **Inheritance ("IS-A")**: A `FlightExpense` **is an** `Expense`.
> - **Composition ("HAS-A")**: A `Trip` **has** `Travelers` and **has** `Expenses`. `Trip` does not inherit from `Expense`; instead, it holds instances of `Traveler` and `Expense` inside its internal collections.

## 🚀 How to Run the Application

This is a clean, dependency-free web application. Because ES6 modules (`import/export`) are used, run it with any local static HTTP server:

### Option A: Using Python (Recommended & Built-in)
Open a terminal in `d:/aoops` and run:
```bash
python -m http.server 8000
```
Then visit: **`http://localhost:8000`** in any web browser.

### Option B: Using Node / npx
```bash
npx serve .
# or
npx http-server .
```

### Option C: VS Code Live Server
Right-click `index.html` in VS Code and select **"Open with Live Server"**.
